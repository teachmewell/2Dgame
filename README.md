Hi, this is the intro into this project. We want to model a 2D game involving a Player, a 2D board and certain things the User can do on it. 

Java is object oriented, meaning that you can create objects just like in the real world. (So you might want to create a stone, a player, etc.)

What properties these objects have is defined in their classes. You can see in the files that we have different classes (files): Board.java, Player.java, etc. 
Each file is named **exactly** as the classes are. So Player.java has the class named Player inside. 

There is a special class named Main.java in which convention defines to run the main() method, aka the method that runs the project. However, this is purely convention and main methods elsewhere work as well. 

As you might imagine, we create a Board, a Player and objects that can each do something. What can each class do? That is defined inside their files.
